
# Satellite-Based Crop Health Monitor

A web application for monitoring vegetation using satellite
imagery and the Normalized Difference Vegetation Index (NDVI).

## Planned features

- Select an agricultural area on an interactive map.
- Retrieve Sentinel-2 satellite imagery.
- Calculate and visualise NDVI.
- Explore vegetation trends over time.

## Technology stack

- Python
- Streamlit
- Google Earth Engine
- Git and GitHub

## Project status

Under development. Satellite data integration is planned.
